# Dark Souls 2: Death Counter & Fast Alt-Tab

Утилита для Dark Souls 2, которая по горячей клавише считает количество смертей и исправляет зависание/черный экран при сворачивании игры Alt+Tab.


## 🚀 Возможности
Счетчик смертей работает по горячим клавишам:

"f1"  # +1 смерть
"f2"  # -1 смерть
"f3"  # показать/скрыть 
"f4"  # сбросить счетчик на 0
"f10"  # полностью выключить скрипт
(в счетчик интегрирован быстрый Alt+Tab)

Также отдельно есть  Alt+Tab без счетчика


## 🛠 Установка и запуск
1. Скачайте последнюю версию со страницы [Releases](ссылка_на_вкладку_releases_вашего_гитхаба).
2. Распакуйте архив в любую папку.
3. Запустите death_counter + fast_alttab.py или ds2_fast_alttab.py 
4. Запустите Dark Souls 2.


## ⚠️ Важно 
❗❗❗В игре нужно поставить оконный режим с разрешением своего экрана. Скрипт сделает экран полноразмерным. ❗❗❗
Также счетчик можно использовать в онлайн так как скрипты не лезут в память игры.
